## About Me

I build Android applications and connected products used in field operations, fleet tracking, and home automation. I enjoy solving the practical challenges behind reliable mobile software: keeping location experiences useful in the background, making core workflows work with limited connectivity, and structuring apps so they are easier to maintain and extend.

My experience includes Android development with Kotlin and Java, modern UI work with Jetpack Compose, application architecture, background synchronization, and location-based features. I have also contributed to an IoT product across Android, iOS, backend services, and NodeMCU, which gives me a broader view of how mobile apps connect with devices and services.

Alongside implementation, I contribute to technical direction, collaborate with cross-functional teammates, and mentor developers.

## Areas of Focus

### Android Application Development

- Build Android features with **Kotlin**, **Java**, and **Jetpack Compose**.
- Structure applications around **MVVM** and **Clean Architecture** to keep responsibilities clear and changes manageable.
- Use **Hilt** for dependency injection, **Room** for local persistence, and **Retrofit** for API communication.
- Integrate **Firebase** and **Google Maps** where they support product needs.

### Location, Background Work & Offline Support

- Develop GPS tracking features for field operations and fleet use cases.
- Work with background location flows and **foreground services** for ongoing tracking.
- Implement **geofencing** and map-based experiences.
- Use **WorkManager** to schedule synchronization and other deferrable background work.
- Design **offline-first** workflows so users can continue working when network access is limited, with local data and later synchronization.

### Technical Leadership & Collaboration

- Help guide implementation choices and break product requirements into maintainable technical work.
- Collaborate across mobile, backend, and product teams to deliver connected features.
- Support teammates through code discussions, knowledge sharing, and mentoring.
